# Mis Finanzas v2
PWA personal de control de liquidez.
- Saldo inicial: 1.664,21 €
- Gasto único: importe + concepto; fecha automática.
- Gasto recurrente: importe + concepto + día del mes.
- Ingreso único: importe + concepto; fecha automática.
- Ingreso recurrente preparado para uso futuro.
- Los recurrentes NO descuentan el saldo al crearlos: son compromisos.
- Cada ocurrencia del mes actual se puede marcar como "Pagado"; entonces se descuenta del disponible y entra al historial.
- El mes siguiente se genera automáticamente desde las reglas recurrentes.
- Los pagos en USD se muestran en USD y su compromiso se estima en EUR con la tasa de referencia configurada; al marcar pagado se descuenta esa conversión.
- Los datos se guardan localmente en el navegador.

En el estado inicial de agosto 2026 se consideran ya pagados Vivienda, Digi, TUSSAM, Basic-Fit y Spotify; quedan pendientes ChatGPT (24) y Apple (27), según la situación indicada por el usuario.
