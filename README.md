# Mis Finanzas v2

Aplicación personal para control de saldo, compromisos mensuales y liquidez en iPhone.

### Cambios principales en la v2:
- **Anti-duplicados:** Evita duplicar plantillas de recurrencias al registrar o pagar gastos.
- **Edición de Cuentas:** Modificación de saldos directo en la interfaz con recálculo automático de liquidez.
- **Gestión de Compromisos:** Permite registrar pagos al instante, modificar montos o cancelar recurrencias futuras sin borrar el historial.
- **Historial Completo:** Nuevo modal de historial de transacciones (accesible desde el botón de la izquierda).
- **Configuración de Tasas:** Modificación fácil del tipo de cambio COP/EUR y USD/EUR.
